Rule-Based Interactive Chatbot

chat_bot.py
Python Datetime Logic Control Flow CLI

Project Overview

Developed a lightweight, continuous-loop command-line chatbot designed to interact with users via predefined rules. This project established a foundation in handling user inputs, data normalization, and dynamic response generation.

Technical Implementation

  • Dynamic Data Integration: Imported Python's datetime module to actively fetch and format real-time system clocks and dates when queried by the user.
  • Dictionary Mapping: Engineered an O(1) response lookup system using Python dictionaries to map distinct user intents to appropriate bot replies.

Iris Species Classification Pipeline

DecodeLabs_AI_Project_2.ipynb
Scikit-Learn Pandas / Seaborn K-Nearest Neighbors (KNN) Confusion Matrix

Project Overview

Engineered an end-to-end supervised machine learning pipeline to classify Iris flower species based on sepal and petal dimensions, focusing on rigorous feature scaling, model selection, and multi-class performance evaluation.

Technical Implementation

  • Exploratory Data Analysis: Utilized seaborn.pairplot to visualize multi-dimensional feature distributions and class boundaries across sepal and petal dimensions.
  • Data Preprocessing & Scaling: Split data using an 80/20 train-test ratio (stratified split across 150 instances, yielding 120 training and 30 test samples) and scaled features using StandardScaler.
  • Model Fitting: Trained a K-Nearest Neighbors classifier (n_neighbors=5) on scaled feature vectors.
  • Confusion Matrix Analysis: Generated and visualized a 3x3 confusion matrix via Seaborn heatmap. The matrix recorded [[10, 0, 0], [0, 9, 1], [0, 1, 9]], showing robust classification handling with minor overlap between Versicolor and Virginica classes.

Digital Career Matchmaker (NLP)

Decodelabs_project_3.ipynb
NLP TF-IDF Vectorization Cosine Similarity Pandas

Project Overview

Built a content-based recommendation engine that analyzes a user's technical skill stack and mathematically pairs them with the most relevant IT job roles from a comprehensive dataset.

Technical Implementation

  • Text Normalization: Designed a custom regex-based cleaning pipeline to standardize terminology (e.g., mapping "ml" to "machine learning") and remove noise from job descriptions and requirements.
  • Vectorization: Applied TfidfVectorizer (with English stop-words removed) to transform unstructured text across 493 job entries into measurable numerical matrices.
  • Similarity Scoring: Computed cosine_similarity between the user's vectorized skill profile and the dataset to rank the closest matches mathematically.
  • Interactive CLI: Developed a robust user interface with integrated help menus, categorized skill dictionaries, and input validation filters.

Computer Vision OCR Engine

optical_charecter_recognition.ipynb
OpenCV (cv2) PyTesseract Image Processing Data Parsing

Project Overview

Developed a visual data extraction pipeline capable of parsing text from raw images by combining traditional computer vision preprocessing with Google's Tesseract OCR engine.

Technical Implementation

  • Image Preprocessing: Handled image loading via OpenCV and applied grayscale conversion. Implemented cv2.adaptiveThreshold (Gaussian) to drastically reduce image noise and create optimal text contrast.
  • Text Extraction: Fed the processed image arrays into pytesseract.image_to_data (Output.DICT) to extract both the recognized text strings and their spatial coordinates as a queryable dictionary.
  • Coordinate Mapping: Extracted bounding box data (Left, Top, Width, Height) to calculate exact text placement on the original image canvas.
